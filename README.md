# offline

An academic CV template without horizontal or vertical lines (this is a bit of a lie at this point, see the CV header!).

Have a look at `example/cv.typ` if you'd like to learn how to use this template.
The example uses some of the wonderful [Phosphor Icons](https://phosphoricons.com/) (MIT-licensed) and fonts from the [`yuan-resume`](https://typst.app/universe/package/yuan-resume) template.
Please make sure to follow their copyrights if you choose to use them yourself.

More documentation coming soon, I hope.
